# Bark 全局通知

首页 → 全局设置 → Bark 通知。支持总开关、定时摘要和出错提醒的独立开关。

地址留空复用本机原有 Hermes Bark 通道，设备 Key 仍由原通道读取；也可以填写 `https://api.day.app/你的Key` 或自建服务的对应地址。不要粘贴带标题、正文、查询参数的完整测试请求。地址默认隐藏，且不会写入前端请求日志或 HTTP 缓存。

可配置通知分组、铃声名称、图标 URL；摘要与出错提醒分别设置提醒级别和标题/正文模板。支持 `{profile}` 配置名、`{title}` 原始主题、`{content}` 原始内容、`{date}` 月日、`{time}` 完整时间。模板不会递归展开原始内容中的花括号。

“保存设置”持久化到后端 `config/global/bark.json`，下次通知读取最新配置。该文件包含可能带设备 Key 的自定义地址，属于本地配置，不提交到 Git。仅关闭 Bark 开关不会改动脚本中独立配置的其他通知通道。

“发送测试”使用尚未保存的表单内容，不改写配置；即使开关关闭也可测试。Bark 服务接受请求不代表手机已展示，需在手机确认。

定时摘要仍由原有 Windows 计划任务调用根目录 `oasx_bark_summary.py`，这里不更改发送时间。摘要保留原日志分析和中文任务名，只统一使用这份通知配置。

出错提醒接入脚本异常处理，包括设备自动恢复失败、游戏卡住或客户端异常、未知页面、脚本异常、需要人工接管、任务连续失败和脚本启动/循环中的未处理异常。已发送提醒的异常退出不会再次发送重复退出提醒。原有单配置通知保留。

新增或更新后端代码时重启后端及正在运行的脚本；之后在全局设置中保存开关、地址或模板无需重启。远程重启未加入。
