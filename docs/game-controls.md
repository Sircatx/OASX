# 总览页游戏卡片

调度器下方使用一张“游戏”卡片。

- 未运行：显示手柄按钮，启动游戏和模拟器。
- 正在运行：显示绿色状态点、手柄和电源按钮。手柄将游戏窗口打开到当前桌面；电源按钮关闭游戏及模拟器，并停止当前方案调度器，防止立即自动拉起。
- 操作过程中显示进度，暂时禁用两个按钮，后端使用同一把锁避免启动和关闭并发。

通过不缓存的 `GET /home/game_status` 每四秒读取实际模拟器进程状态，不依赖上次点击记录。状态检查不创建 Device、不连接 ADB，也不启动模拟器。后台读取失败不弹出重复提示。

`POST /home/stop_game` 在关闭前检查其他实例及使用同一模拟器的其他活动方案。关闭使用现有完整关闭流程，但不调用带自动重新启动重试的 `emulator_stop()`；模拟器已关闭时直接成功。

使用前同步更新 OnmyojiAutoScript 的 `windows-runtime` 分支和 OASX 本分支。手柄手动启动会将游戏显示到当前桌面；调度器自动启动使用其他虚拟桌面。点击电源关闭后，如需继续定时自动运行，请重新启动调度器。

验证：Dart 静态检查通过，20 项后端测试通过，Release 构建完成并部署，安装版与构建版 app.so 哈希一致。实机确认未运行时只显示一张“游戏”卡片和手柄按钮；当前另一 MuMu 实例运行《部落冲突》时，阴阳师状态仍正确为未运行。关闭路径通过后端测试，本次未为测试退出用户正在使用的其他游戏。
